= Stage replay matrix

This page records which consumer replays which pinned generation of each
stage language, at which boundary, on which runtimes and operating systems,
and the evidence for each entry. The state was read from GitHub on
2026-11-05. Only merged work with a passing replay counts as done. Open pull
requests, failing runs and local-only branches are listed as pending.

The boundaries are the raw tree, the typed model, the model roundtrip and the
facade, as defined in the stage corpus contract. Runtimes are Ruby, Rust and
WASM/TS. Operating systems are ubuntu, windows and macos.

The html stage has no consumer replaying it yet. The roundtrip stage is
replayed by plurimath, but that pull request is still open. Rust replay of
latex generation 3 (139 of 139 rows) is open in parsanol-rs. A WASM/TS replay
exists only as a local, unpushed parsanol-ts branch, so it is pending and has
no evidence yet.

Two Ruby entries need care. The umath platform pull request was merged while
its replay jobs were failing, and the corpus workflow on umath main also
failed at that merge, so unicode is not done on windows or macos. The latex
generation 3 pin in latexmath is open and its full replay is failing, so latex
counts as done for generation 2 only.
