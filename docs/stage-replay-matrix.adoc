= Stage replay matrix

This page records which consumer replays which pinned generation of each
stage language, at which boundary, on which runtimes and operating systems,
and the evidence for each entry. The state was read from GitHub on
2026-11-10. Only merged work with a passing replay counts as done. Open pull
requests, failing runs and local-only branches are listed as pending.

The boundaries are the raw tree, the typed model, the model roundtrip and the
facade, as defined in the stage corpus contract. Runtimes are Ruby, Rust and
WASM/TS. Operating systems are ubuntu, windows and macos.

The html stage has no consumer replaying it yet. Every other stage is
replayed by at least one merged consumer with a passing run.

The Rust and WASM/TS replays of the raw-tree rows were first added to
parsanol-rs (#410 and #412) and proposed for parsanol-ts (#55). They now live
in this repository, in `engines/` and the `engine-replays` workflow
(plurimath-testsuite#45). parsanol-rs#414 removed the copy there, and
parsanol-ts#55 was closed without merging.

The umath platform pull request (umath#16) was merged while its replay jobs
were failing on all three operating systems. Unicode is done on windows and
macos from generation 4, pinned by umath#19, whose merge passed the replay on
all three.
